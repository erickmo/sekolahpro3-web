Ekstrakurikuler

Domain manajemen kegiatan ekstrakurikuler di sekolah, mencakup katalog program, pendaftaran siswa, pencatatan kehadiran per sesi, dan pelaporan predikat akhir semester. Mendukung program internal (pembina guru) dan kemitraan pihak ketiga (Mitra) dengan rekap kehadiran otomatis dan penilaian berbasis persentase.

Arsitektur

  • Backend: Module Ekstrakurikuler di apps/sekolahpro (repo terpisah); 5 doctype terdaftar di tenant_registry.py DOCTYPES["SCHOOL"].
  • Frontend: Web routes /sch/$sekolah/ekstrakurikuler di apps/school; Tahun Ajaran + Semester context via EkskulContextProvider.
  • Shared packages: @sekolahpro/api-client, @sekolahpro/auth, @sekolahpro/ui.

Doctypes / Entitas

Doctype Peran Field Kunci
Ekstrakurikuler Program master; rekam program ekstrakurikuler dengan pembina, jadwal, kuota nama, pembina, penyelenggara (Internal/Mitra), status, kuota, jam_mulai, jam_selesai
Mitra Ekstrakurikuler Partnership master; rekam mitra penyedia (dojo, musik, pelatih khusus) nama, kontak, alamat, tanggal_mulai_mou, tanggal_akhir_mou
Pendaftaran Ekstrakurikuler Enrollment siswa ke program dengan validasi kuota; kuota di-lock via SELECT FOR UPDATE siswa, program, tanggal_pendaftaran, status (Aktif/Keluar)
Sesi Ekstrakurikuler Session (pertemuan) program pada hari/jam tertentu; roster dari pendaftaran Aktif program, semester, tahun_ajaran (fetch_from semester, read_only), tanggal, pertemuan_ke (auto), topik
Kehadiran Ekstrakurikuler (child) Attendance row per siswa per sesi; no tenant fields (tenant on parent Sesi) siswa, status (Hadir/Izin/Sakit/Alpha), catatan
Raport Ekstrakurikuler End-of-semester report per siswa+program; rekap kehadiran snapshot lazy + predikat editable siswa, program, semester, tahun_ajaran (fetch_from, read_only), jumlah_hadir, jumlah_pertemuan, persentase_kehadiran (snapshot), predikat, deskripsi, status (Draft/Final)

Alur Utama

  1. Koordinator: Buat Ekstrakurikuler program (pilih penyelenggara Internal → set pembina, atau Mitra → pilih mitra). Opsional catat Mitra Ekstrakurikuler + MOU.
  2. Koordinator: Daftarkan siswa via Pendaftaran Ekstrakurikuler; kuota dijaga otomatis dengan row lock (FOR UPDATE) agar tidak terlewati.
  3. Pembina: Buka layar "Sesi & Kehadiran", mulai sesi hari ini (auto pertemuan_ke, semester dari konteks); roster ter-prefill dari pendaftaran Aktif, semua default Hadir. Tandai pengecualian saja (Izin/Sakit/Alpha); autosave per row state.
  4. Pembina (akhir semester): Buka "Raport", generate semua peserta. Rekap kehadiran (jumlah_hadir, jumlah_pertemuan, persentase) ter-compute lazy via single GROUP BY snapshot, predikat auto-saran dari % kehadiran (editable, ≥90 Sangat Baik / ≥75 Baik / ≥50 Cukup / <50 Kurang).
  5. Raport terbit: Status Draft → Final memicu predikat wajib. Snapshot stabil untuk referensi wali.

Aturan & Kebijakan

  • Kuota enforcement: Pendaftaran.validate() mengambil SELECT … FOR UPDATE pada parent Ekstrakurikuler, kemudian count pendaftaran Aktif. Kuota 0 = unlimited. Tidak ada racy check.
  • Duplikat pendaftaran: Pendaftaran aktif duplikat (siswa+program) diblok; rejoin = row baru.
  • Kehadiran roster: Sesi.validate() menolak baris Kehadiran untuk siswa tanpa Pendaftaran Aktif (eligibility guard).
  • Denominator rekap: Hanya baris Kehadiran milik siswa itu di (program, semester) — tidak semua sesi program. Benar untuk peserta tengah-semester. Zero sesi → 0% (bukan NaN).
  • Periode read-only: tahun_ajaran di Sesi dan Raport adalah fetch_from semester.tahun_ajaran, read-only, agar pasangan (semester, TA) tidak desync saat sorting/grouping.
  • TA-closed immutability: Sesi, Pendaftaran, Raport immutable ketika Tahun Ajaran status = Closed (via tahun_ajaran.status). Program dan Mitra spans TA → tidak TA-locked.
  • Predikat timing: Raport punya Select status (Draft/Final). Predikat required hanya saat status=Final, jadi snapshot rekap ter-persist dulu, pembina grade setelahnya.
  • Role-based framing: useEkskulRole() mengidentifikasi pembina / koordinator / kepala dari Frappe role string untuk framing UX. Permissive fallback: when no role matches, grant semua role agar UI tidak pernah tersensor. Backend tetap guard via tenant_registry + doctype permissions.

Cross-Domain Events

Triggers (memicu)

  • Saat status Tahun Ajaran berubah ke Closed: Sesi, Pendaftaran, Raport become immutable (guard di validate).
  • Saat siswa diunroll (Pendaftaran status → Keluar): (future) soft-alert kepada pembina untuk rekap; currently masuk record saja.

Listens (bereaksi)

  • Tahun Ajaran.status = Closed: immutability check di Sesi/Pendaftaran/Raport validate().
  • Siswa.status: enrollment eligibility (Sesi validate rejects kehadiran for non-Aktif siswa jika diterapkan; currently trusts Pendaftaran Aktif sebagai source-of-truth).
  • Semester.tahun_ajaran: fetch_from source untuk Sesi + Raport tahun_ajaran (read-only, ensures grouping consistency).

Batas Ruang Lingkup (YAGNI)

  • Wali notification: Raport field shape (persentase_kehadiran, predikat, deskripsi) ready untuk future wali surface; v2 task emit ekstrakurikuler.raport.final event dan wiring ke rapor-page.
  • MOU expiry soft-alert: Mitra.tanggal_akhir_mou bersifat informasional; no auto-status-flip. Koordinator/kepala cek manual. V2 future: ekstrakurikuler.mitra.mou_expired event + email alert.
  • Finance integration: Fee info di Pendaftaran/Program bersifat informasional; finance app owns actual payment. No feeder.
  • Pre-enrollment waitlist: Deferred untuk v2. Pendaftaran tutup ketika kuota penuh (display gate).
  • Live rekap updates: Raport snapshot stabil saat tersimpan. Kehadiran perubahan setelah itu → Raport refresh hanya when user re-open + save. Accepted trade-off untuk avoid N+1 on frequent autosave di layar absensi.

Rute Ekstrakurikuler dipindah ke bawah workspace Akademik per-TA, dengan segmen URL disingkat.

  • Rute baru: /sch/$sekolah/akademik/$ta/ekskul/* (8 rute: index, program, program.$name, pendaftaran, sesi, raport, mitra, mitra.$name). Segmen URL disingkat ekstrakurikuler → ekskul.
  • Rute lama: /sch/$sekolah/ekstrakurikuler/* — stub redirect (sch.$sekolah.ekstrakurikuler.index.tsx + sch.$sekolah.ekstrakurikuler.$.tsx) redirect ke hub /akademik?go=ekskul.
  • EkskulContextProvider: Tetap aktif di bawah layout sch.$sekolah.akademik.$ta.ekskul.tsx; mengonsumsi $ta dari workspace untuk set default TA.
  • Nav grup Kegiatan: Ekskul masuk grup Kegiatan di workspace nav (bersama Jadwal).
