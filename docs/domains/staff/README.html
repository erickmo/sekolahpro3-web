Guru & Staf (Kepegawaian)

Modul kelola data pegawai (guru dan staff) sekolah, mencakup profil, penugasan mengajar, SK legal (SK Mengajar/SK Jabatan), dan berkas kepegawaian dengan tracking masa berlaku otomatis. Mendukung dual-role (guru yang juga staff). Peran: admin TU / operator kepegawaian.

Arsitektur

  • Backend modul Frappe: sekolahpro.akademik.* (repo terpisah /frappe/apps/sekolahpro/)
  • Web route prefix: /sch/$sekolah/staff — single hub untuk guru & staff (merge dari dua menu lama)
  • Shared packages: @sekolahpro/api-client (frappeFetch, useResourceList), @sekolahpro/ui (DataTable, Badge, modals)
  • Pure logic layer: lib/orang/ — staffStats, nav, glossary (testable tanpa hooks/I/O)
  • Sub-navigasi: GroupedNavTabs + STAFF_NAV_GROUPS (lib/orang/nav.ts) — task-intent groups: Ringkasan, Data Pokok, Penugasan Mengajar, Kepegawaian

Alur utama

  1. Dashboard Ringkasan: Stat cards (total, aktif, sertifikasi %), donut role (Guru|Staff|Dual), bar status kepegawaian, gender dist, attention queue (pegawai non-aktif, guru belum sertifikasi)
  2. Daftar Pegawai: List + filter (role/status/cari) → klik → detail $nip dengan tab adaptif (Profil, Mengajar, Kepegawaian, Berkas, Kehadiran)
  3. Jalur Guru (Penugasan Mengajar):
    • Mapel Pengampu — tetapkan guru ↔ mapel ↔ kelas
    • Penugasan — buat penugasan (JJM); row aktif → tombol "Buat SK" (1:1) atau bulk generate per TA
    • SK Mengajar — list SK; workflow: Draft → Diajukan → Disetujui Kepsek → Diterbitkan / Dicabut; QR generated saat Diterbitkan
  4. Jalur Staff (Kepegawaian):
    • Jabatan — master jenis jabatan (tambah/edit)
    • SK Jabatan — terbitkan SK posisi (sama workflow SK Mengajar)
  5. Berkas (cross-role): List berkass guru; per-baris tombol "Perpanjang" extend masa berlaku; scheduler daily 09:00 flag-expired + publish renewal alert H-30 via realtime + Notification Log

Aturan & Kebijakan

  • Role classification: Pegawai.roles[] contains {"role": "Pegawai Guru"} and/or {"role": "Pegawai Staff"} — dual-role didukung penuh. Helper: apiIsGuru(p) / apiIsStaff(p) / apiIsDualRole(p)
  • UI adaptivity: Mapel Pengampu & Penugasan hanya tampil untuk guru; SK Jabatan & tab Kepegawaian hanya untuk staff; tab Mengajar + SK Mengajar hanya untuk guru
  • Status kepegawaian domain: PNS, PPPK, GTY, GTT, Tetap Yayasan, Kontrak, Honorer — PNS/PPPK wajib punya NIP; PNS wajib punya Nomor Karpeg
  • Sertifikasi scope: Coverage computed atas guru saja (incl. dual-role); pure staff excluded agar % meaningful; divide-by-zero guard (pct=0 kalau no guru)
  • Penugasan aktif guard: Guru dengan Penugasan Aktif tidak boleh dihapus — operator wajib nonaktifkan penugasan dulu
  • SK Mengajar workflow: Hanya boleh Diterbitkan kalau Penugasan Guru berstatus Aktif; SK Diterbitkan immutable (R-AKD-SK-01) — pembatalan via SK Pencabutan baru (field sk_pencabutan_ref wajib)
  • Berkas kadaluarsa: Scheduler sync stale flags (tanggal_kadaluarsa < today tapi status != Expired); notify renewal H-30; idempotent (tanggal_renewal_notif guard); dokumen tanpa tanggal_kadaluarsa (Ijazah) skip otomatis
  • Nomor SK auto-fill: Sebelum SK Mengajar diterbitkan, nomor_sk_manual di-auto-fill dari Konfigurasi Nomor Surat kalau kosong (idempotent — manual override menang)

Cross-Domain Events

Triggers (memicu)

  • akademik.sk_mengajar.diterbitkan — published saat SK Mengajar.on_submit() (Diterbitkan). Payload: {name, guru}. Use case: downstream sistem (mis. payroll, absensi) subscribe untuk tracking periode mengajar legal. Published via Frappe realtime dengan after_commit=True

Listens (bereaksi)

  • Berkas Guru renewal alert (internal scheduler event) — daily 09:00 via scheduler hook flag_expired_and_notify. Publish realtime berkas_renewal_alert ke channel koperasi.berkas.expire + insert Notification Log. NOT sebuah Frappe event — adalah scheduled aggregation + multi-channel broadcast (realtime + notif log)

Batas ruang lingkup (YAGNI)

  • Master data Tahun Ajaran, Mapel, Kurikulum, KKM — documented under akademik domain; tidak di-duplikasi di sini
  • Absensi guru — tersendiri di modul absensi; kepegawaian hanya track keterkaitan. Jadwal mengajar — di modul jadwal
  • Mobile app guru (apps/guru) — separate codebase; reuses backend mobile/v1/ endpoints; chat/nilai/absensi via separate auth flow
  • Payroll, kompensasi — tidak di-scope modul ini; hanya data identitas & legal basis (SK)
  • Dapodik sync — integration_dapodik modul; pegawai hanya data source
