Ads Manager

Platform banner-ads: dikelola dari aplikasi SaaS admin, ditayangkan di semua aplikasi SekolahPro lain. Setiap aplikasi konsumen = satu Property yang dilacak (impression & klik).

Arsitektur

  • Backend: app Frappe vernon_ads (repo terpisah), di-install di site sekolahpro.localhost. 7 doctype + API guest get_ad/track/click + endpoint admin stats.overview.
  • Paket bersama: @sekolahpro/ads — <AdsProvider baseUrl propertyKey> + <AdBanner slot> + useAd + client (fetchAd/trackImpression/resolveClick).
  • Admin: modul /ads/* di apps/saas — dashboard analitik + CRUD (customer, group, property, slot, campaign, creative) lewat Frappe resource API. Gate role SekolahPro Admin.
  • Konsumen: 6 app (school, parent, student, merchant, landing, situs) dibungkus <AdsProvider> + memasang <AdBanner> di slot bernama.

Alur penayangan

  1. <AdBanner slot="school-dashboard-top"> mount → GET get_ad?slot&property_key.
  2. Backend select_creative: Property(api_key, Active) → Ad Slot(slot_key, property) → Campaign aktif (property_group, tanggal) → Ad Creative cocok (ad_type, ukuran, Active) → pilih acak. Balikan: creative + token HMAC + url track/klik.
  3. Banner tampil. Saat ≥50% terlihat → POST track {token} (Impression, sekali).
  4. Klik → GET click?token → catat Click → window.open(redirect).

Endpoint analitik

vernon_ads.api.stats.overview(from_date, to_date) (whitelist, perlu sesi) — total impression/klik, breakdown per campaign & per property, dan deret harian. CTR dihitung di sisi klien. Default 30 hari terakhir.

Slot bawaan (seed)

after_install men-seed 1 Property Group (SekolahPro Apps) + 6 Property (satu per app, api_key auto) + 3 slot per property: <app>-dashboard-top (728×90), <app>-sidebar (300×250), <app>-content-bottom (728×90). Key memakai tanda hubung (slug-safe).

Konfigurasi konsumen (env)

Tiap app set VITE_ADS_PROPERTY_KEY = api_key Property-nya. VITE_ADS_BASE kosong untuk app same-origin (school/parent/student/merchant, lewat proxy) dan http://sekolahpro.localhost untuk app cross-origin (landing/situs, perlu CORS). Provider no-op bila key kosong.

Keamanan

  • Token HMAC bertanda (TTL 24 jam) menggerbang track/klik — creative ID tak bisa dipalsukan. Secret di site_config.vernon_ads_token_secret.
  • api_key = read-key publik (serve guest), aman ditaruh di env app.
  • CORS dibatasi ke origin landing/situs, bukan *.
  • body_html tidak dirender di FE ronde ini (banner gambar saja) → tanpa permukaan XSS.

Cross-Domain Events

Triggers (memicu)

Tidak ada. Domain ini self-contained — tidak memancarkan event ke domain lain.

Listens (bereaksi)

Tidak ada. Tidak mendengarkan event domain lain.

Batas ruang lingkup (YAGNI)

  • Hanya banner gambar (ad_type Banner). Video/Native/Interstitial ditunda.
  • Tanpa budget pacing / billing otomatis, tanpa frequency capping / geo-targeting (seleksi acak).
