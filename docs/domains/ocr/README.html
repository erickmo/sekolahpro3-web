OCR Identitas (KTP / KK / SIM)

Pemindaian on-prem dokumen identitas Indonesia (KTP, Kartu Keluarga, SIM) menggunakan Tesseract untuk mengisi otomatis formulir data orang (Siswa, Wali, Pegawai/Staf, PPDB Calon Siswa, Pickup Person). Pengguna selalu meninjau dan dapat mengedit semua field yang diekstraksi sebelum menyimpan. Didesain dengan privasi-pertama: pemrosesan on-prem, persetujuan eksplisit, auto-purge 30 hari, dan field sensitif terbatasi permlevel.

Arsitektur

  • Backend Frappe module: sekolahpro.ocr — modul baru lintas domain; API whitelisted di sekolahpro.ocr.api
  • Doctype utama: Pindai Identitas — record audit consent + hasil scan + retensi (detail di bawah)
  • OCR engine: sekolahpro/ocr/engine/ — modul-modul murni (pure, tanpa DB, tanpa session): preprocess.py (Pillow), tesseract.py (pytesseract, lang=ind), parser.py (KTP/KK/SIM), constants.py
  • Shared component: <IdScanField> di @sekolahpro/ui — consent gate → kamera/file capture → OCR → review → terapkan ke form
  • Shared component: <Turnstile> di @sekolahpro/ui — dipakai di endpoint publik PPDB
  • Per-app API client: masing-masing app menginject onScan(blob, jenis) ke <IdScanField>; komponen bebas dari API client apapun
  • Per-form mapping: fungsi murni per form (Siswa, Wali, Pegawai, PpdbForm, PickupPerson) — parsed dict → field form masing-masing

Doctype: Pindai Identitas

Anchored, tenant-scoped. Terdaftar di tenant_registry.py DOCTYPES['SCHOOL'].

Field Tipe Catatan
naming_series Data PINDAI-.YYYY.-.#####
jenis_dokumen Select KTP / KK / SIM; required
file_dokumen Attach Image Private (is_private=1); tidak dapat diakses tanpa session + izin
status Select Diproses / Berhasil / Gagal
confidence Float Rata-rata word confidence Tesseract 0–100
raw_text Long Text permlevel 2 — sensitif; hanya Tata Usaha, Kepala Sekolah, Operator Dapodik, System Manager
hasil_json Code (JSON) permlevel 2 — dict hasil parse; field hilang diomit, tidak pernah ditebak
nik_terdeteksi Data permlevel 2 — NIK tervalidasi 16 digit
consent_diberikan Check Required sebelum scan diproses; ditampilkan di UI sebelum kamera aktif
consent_timestamp Datetime Diset saat consent diberikan
hapus_setelah Date Tanggal purge retensi; diset otomatis via validate(): nowdate() + RETENTION_DAYS
uploaded_by Link User Read-only; diisi otomatis = session user
sekolah Link Sekolah Tenant anchor
organisasi Link Organisasi Tenant anchor; fetch dari sekolah

Controller (pindai_identitas.py)

  • proses_ocr() — load bytes file_dokumen → preprocess → tesseract (lang=ind) → parser.parse_<jenis> → simpan raw_text / hasil_json / confidence / nik_terdeteksi, set status, return parsed dict
  • validate() — set hapus_setelah; pastikan consent_diberikan

Endpoints (sekolahpro/ocr/api.py)

Endpoint Auth Keterangan
scan_identitas Autentikasi (session Frappe) Untuk app school + parent (Siswa, Wali, Pegawai, Staf, PickupPerson). Validasi MIME + ukuran → buat Pindai Identitas → proses_ocr() → return {scan_id, fields, confidence, jenis}.
scan_identitas_publik Guest (allow_guest=True) Untuk form PPDB publik (apps/situs PpdbForm + apps/landing). Tambahan: rate-limit + Cloudflare Turnstile. Selain itu identik dengan endpoint autentikasi.
purge_kadaluarsa Scheduler (internal) Dipanggil oleh scheduler_events["daily"]. Hapus Pindai Identitas (beserta file private tertaut) yang hapus_setelah < today.

Setiap entrypoint ≤ 10 baris; delegasi ke controller. Upload guard (_check_rate_limit, _validate_turnstile, ALLOWED_UPLOAD_MIME, MAX_UPLOAD_BYTES) diekstrak ke sekolahpro/utils/upload_guard.py dan digunakan bersama oleh ppdb/api/ppdb.py.

Engine OCR (sekolahpro/ocr/engine/)

  • preprocess.py — Pillow: grayscale, autocontrast, resize, binarize (pure bytes→bytes)
  • tesseract.py — pytesseract wrapper: image bytes → (text, confidence); lang=ind (pure)
  • parser.py — parse_ktp / parse_kk / parse_sim: text → dict; regex + label-anchored line parsing. NIK divalidasi 16 digit; tanggal dinormalisasi ke YYYY-MM-DD. Field tidak ditemukan → diomit (tidak pernah ditebak)
  • constants.py — RETENTION_DAYS = 30, pola regex, field maps, kunci doctype

Field yang diekstrak per jenis dokumen

Jenis Field yang diekstrak
KTP nik, nama, tempat_lahir, tanggal_lahir, jenis_kelamin, alamat, rt_rw, kel_desa, kecamatan, agama, status_perkawinan, pekerjaan, kewarganegaraan
KK no_kk, alamat, rt_rw, desa_kelurahan, kecamatan, kabupaten_kota, provinsi, kode_pos, anggota[] (tiap anggota: nik, nama, jenis_kelamin, tempat_lahir, tanggal_lahir, agama, pendidikan, pekerjaan, status_hubungan)
SIM nama, alamat, tempat_lahir, tanggal_lahir, no_sim, nik (hanya SIM generasi baru yang mencetak NIK)

Alur utama

  1. Consent: Operator/pelamar klik checkbox consent di <IdScanField>; UI baru mengaktifkan tombol kamera/file
  2. Capture: Foto via getUserMedia (mobile) atau file picker; canvas downscale ke ≤ 1 MB JPEG-0.8
  3. Upload + OCR: Blob dikirim ke scan_identitas atau scan_identitas_publik; backend buat Pindai Identitas, jalankan proses_ocr(), return fields + confidence
  4. Review: Panel review tampil: daftar field terparsing + confidence; operator periksa / koreksi
  5. Terapkan: Klik "Terapkan ke formulir" → fungsi mapping per-form isi field form; tidak ada yang disimpan ke doctype orang tanpa operator menekan Save
  6. Purge: Scheduler harian hapus Pindai Identitas + file private setelah hapus_setelah

Frontend — Komponen & Wiring

Shared (@sekolahpro/ui)

  • <IdScanField> — consent gate → capture → OCR review → apply. Props: jenis, onScan(blob, jenis) => Promise<fields> (diinject per app), onApply(fields) (parent map ke form state). Gunakan Modal + Button dari @sekolahpro/ui

  • Catatan: Setiap paket yang mengonsumsi source @sekolahpro/ui harus mendeklarasikan react-dom (deps + peer) karena Modal.tsx menggunakan createPortal

Privasi & Kepatuhan UU PDP

  • On-prem processing: Tesseract berjalan di container backend; gambar tidak pernah dikirim ke pihak ketiga
  • Private file: file_dokumen disimpan sebagai private Frappe file (is_private=1); tidak dapat diakses tanpa session + izin
  • Permlevel-gated sensitive fields: raw_text, hasil_json, nik_terdeteksi — permlevel 2; hanya peran: Tata Usaha, Kepala Sekolah, Operator Dapodik, System Manager
  • Consent eksplisit: Checkbox consent_diberikan wajib dicentang di UI sebelum scan aktif; timestamp consent direkam di doctype
  • Auto-purge 30 hari: Scheduler harian hapus Pindai Identitas + file private setelah RETENTION_DAYS = 30
  • Tenant isolation: Field sekolah + organisasi sebagai tenant anchor; doctype terdaftar di tenant_registry.py — tidak ada cross-tenant leak
  • Review sebelum simpan: Field hasil OCR mengisi form yang dapat diedit; tidak ada data yang dipersist ke record orang tanpa operator menekan Save

Deployment

  • System deps (BLOCKER): Backend container harus memiliki tesseract-ocr + tesseract-ocr-ind via apt-get (dideklarasikan di pyproject.toml [deploy.dependencies.apt] + Dockerfile/compose override)
  • Python deps: pytesseract + Pillow di sekolahpro packaging (pyproject.toml / requirements.txt) sehingga bench setup requirements menginstalnya
  • Verifikasi: tesseract --list-langs harus menampilkan ind
  • Dev bootstrap: Sediakan perintah runtime install sekali pakai untuk dev container sebelum image dibangun ulang

Pengujian

  • BE parser unit: Fixture raw-text sintetis KTP/KK/SIM di tests/testdata/ocr/ (bukan gambar ID asli — privasi); assert parsed dict, validasi NIK, normalisasi tanggal, ekstraksi multi-anggota KK
  • BE controller + endpoint: Penolakan MIME/ukuran, rate-limit, Turnstile, guest vs authed, tenant scoping, consent-required, retention purge — total ~30 pytest
  • FE vitest: <IdScanField> (mock onScan), setiap fungsi mapping per-form, RTL render + perilaku consent-gate
  • Acceptance: Scan manual KTP asli di dev (didokumentasikan di plan; gambar tidak di-commit)

Cross-Domain Events

Feeds (mengisi domain lain)

OCR tidak memicu domain event apapun. Pengisian field bersifat sinkron via API response: field terparsing langsung diterapkan ke state form di sisi klien. Tidak ada event queue, tidak ada webhook, tidak ada trigger ke domain lain.

Sumber Tujuan Mekanisme
Pindai Identitas.hasil_json Form Siswa API response → onApply(fields) → mapping fn → form state (sinkron, tidak ada event)
Pindai Identitas.hasil_json Form Wali Siswa API response → onApply(fields) → mapping fn → form state (sinkron)
Pindai Identitas.hasil_json Form Pegawai / Staf API response → onApply(fields) → mapping fn → form state (sinkron)
Pindai Identitas.hasil_json Form Calon Siswa (PPDB) API response → onApply(fields) → mapping fn → form state (sinkron, guest via Turnstile)
Pindai Identitas.hasil_json Form Pickup Person API response → onApply(fields) → mapping fn → form state (sinkron)

Listens (bereaksi pada event domain lain)

  • Tidak ada. OCR module tidak listen ke event dari domain manapun.

Batas ruang lingkup (YAGNI)

  • Cloud OCR: Tidak ada provider OCR pihak ketiga; hanya Tesseract on-prem
  • Face-match / liveness: Verifikasi keaslian KTP di luar cakupan ini
  • Dokumen lain: Paspor / KIA / Akta Kelahiran — hanya KTP/KK/SIM di fase ini
  • Bulk scanning: Multi-dokumen sekaligus tidak didukung
  • KK → auto-fill peran orang tua: Parser anggota[] memiliki status_hubungan tapi auto-assign peran Ayah/Ibu dari nilai ini ditunda (variance antar template Dukcapil); operator mengisi manual
  • Confidence badge di UI: Nilai confidence direkam di doctype tapi belum ditampilkan sebagai badge di UI (fase berikut)
  • Token Turnstile multi-scan: Token Turnstile single-use; multi-scan dalam satu sesi memerlukan token baru setiap kali (known limitation)
